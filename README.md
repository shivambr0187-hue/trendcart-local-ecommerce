# TrendCart Local Ecommerce

A polished, responsive storefront concept for a neighborhood-first, multi-vendor marketplace. Discover local shops, browse fresh finds, and support independent businesses around you.

## Run locally

No build step or package installation is required. Open `index.html` in a modern browser, or serve the project locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## What's included

- Responsive marketplace landing page inspired by the supplied TrendCart blueprint
- Local category browsing, featured shops, search, and category filters
- Interactive shopping cart with quantity controls and subtotal
- Favorites, newsletter sign-up interaction, and mobile navigation
- Shop-partner call to action and marketplace workflow overview

## Notes

This is a front-end demonstration. Checkout, account, and location-selection actions are demo interactions and are not connected to a backend. Product and shop content is illustrative; images are loaded from Unsplash and Google Fonts are loaded remotely.
